# Currency Converter Web App

A real-time currency converter web application built using HTML, CSS, and JavaScript with API integration for live exchange rates.

## 🚀 Features

- Gets live exchange rates via API
- Converts between currencies instantly
- Responsive and clean UI
- Swap currency function

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Exchange Rate API

## 🔮 Future Improvements

- Add historical exchange rate graphs
- Add dark mode feature
- Add user input validation enhancements

## 📌 Learning Outcomes

- Working with APIs using fetch()
- DOM Manipulation
- Asynchronous JS
- Frontend UI design
